Política de Privacidade

Última actualização: Outubro de 2026

1. Responsável pelo tratamento

Frederico Esgalhado, psicólogo clínico, responsável pela plataforma Psiagora (psiagora.com). Contacto: frederico.e@psiagora.com.

2. Dados recolhidos

Recolhemos apenas os dados estritamente necessários para a prestação do serviço:

  • Nome completo — para identificação e criação do evento no calendário.
  • Endereço de email — para envio de confirmação, lembretes e link de videochamada.
  • Número de telefone (opcional) — para contacto em caso de necessidade.
  • Notas sobre a consulta (opcional) — informação partilhada voluntariamente pelo cliente.
  • Dados de pagamento — processados directamente pela Stripe; a Psiagora não tem acesso aos dados do cartão.

3. Finalidade do tratamento

Os dados são tratados exclusivamente para:

  • Gerir o agendamento e confirmação de consultas.
  • Enviar comunicações relacionadas com a marcação (confirmação, lembrete, remarcação).
  • Processar o pagamento através da Stripe.
  • Criar o evento no Google Calendar e o link Google Meet.

Não utilizamos os dados para fins de marketing, publicidade ou análise de comportamento.

4. Base legal

O tratamento baseia-se na execução do contrato de prestação de serviços (artigo 6.º, n.º 1, alínea b) do RGPD) e, em certas circunstâncias, no legítimo interesse do responsável pelo tratamento.

5. Partilha de dados com terceiros

Os dados são partilhados apenas com os seguintes subcontratantes, estritamente para execução do serviço:

  • Stripe — processamento de pagamentos. Política de privacidade.
  • Google (Calendar, Meet, Gmail) — agendamento, videochamada e comunicações. Política de privacidade.
  • GitHub Pages — alojamento do website. Política de privacidade.

Não vendemos, alugamos nem partilhamos os seus dados com terceiros para fins comerciais.

6. Conservação dos dados

Os dados são conservados pelo período necessário ao cumprimento das finalidades descritas e das obrigações legais aplicáveis. Os registos de marcações são mantidos por um período máximo de 5 anos, salvo obrigação legal de prazo superior.

7. Seus direitos (RGPD)

Tem direito a:

  • Acesso — saber que dados temos sobre si.
  • Rectificação — corrigir dados incorrectos.
  • Apagamento — solicitar a eliminação dos seus dados ("direito ao esquecimento").
  • Portabilidade — receber os seus dados num formato estruturado.
  • Oposição — opor-se ao tratamento em determinadas circunstâncias.
  • Limitação — solicitar a limitação do tratamento.

Para exercer qualquer um destes direitos, contacte frederico.e@psiagora.com. Tem também o direito de apresentar reclamação à Comissão Nacional de Protecção de Dados (CNPD) em cnpd.pt.

8. Segurança

Adoptamos medidas técnicas e organizacionais adequadas para proteger os seus dados contra acesso não autorizado, perda ou destruição, incluindo comunicações cifradas (HTTPS) e acesso restrito às bases de dados de agendamentos.

9. Alterações a esta política

Podemos actualizar esta política periodicamente. A data da última actualização está indicada no topo desta página. Alterações significativas serão comunicadas por email aos clientes activos.
